# Idealized BaTiO₃ path

The reference uses ideal perovskite fractional coordinates in a tetragonal cell with a = 4.00 Å and c = 4.10 Å. The polar structure shifts Ti by +0.02, apical O by −0.03, and planar O by −0.02 along fractional z. Both structures use the same cell. The example uses inversion to generate the other endpoint.

These structures are illustrative. A material study should use reference and polar structures appropriate to the phase and boundary conditions being investigated.
